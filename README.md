# ThreeDViewing - Praktikum Grafika Komputer Minggu 10

Java 17+ | Maven | LWJGL 3.3.3 (GLFW + OpenGL) | JOML 1.10.5

Jalankan:  mvn compile exec:java      (atau Run pada ThreeDViewing.java di VS Code)

Kontrol
- Drag mouse kiri / panah : orbit kamera      - Scroll / W,S : zoom
- 1 Orthographic  2 Isometric  3 Oblique Cavalier
- 4 Persp. 1-titik  5 Persp. 2-titik  6 Persp. 3-titik
- SPASI : anaglyph merah-cyan ON/OFF (moda 4/5/6)   - [ ] : IPD   - , . : konvergensi
- - = : FOV      - R : reset      - ESC : keluar
